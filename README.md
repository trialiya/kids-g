# Который час? / What time is it?

Учебная игра для детей: определяем время по стрелочным часам. Работает в браузере на телефоне и компьютере, умеет ставиться на главный экран (PWA) и работать без интернета. Язык: RU / EN.

**Играть:** https://trialiya.github.io/kids-g/

## История с Барсиком (по умолчанию)
Ребёнок помогает коту Барсику, который не умеет читать часы. Три главы по возрастанию сложности:
1. **День Барсика** — ровно и половина часа, выбор из 4; награда — рыбки.
2. **Чай у Барсика** — четверти и по 5 минут, выбор из 4; награда — чашки.
3. **Мастерская Барсика** — время ставится стрелочками, до «любых минут»; награда — шестерёнки.

За остановку, пройденную на 4 из 5, ребёнок получает наклейку в **альбом** (за 5 из 5 — золотую, за всю главу — большую). За звёзды открываются **наряды Барсика** (бантик, шарфик, очки, шапочка, веночек, корона): выбранный наряд Барсик носит везде. У каждой остановки свои **часы** — кухонные, будильник, с ушками Зайки, с шестерёнками, башенные (`src/js/clock-themes.js`).

Глава 4 «Ошибки Ню» — игра «Найди ошибку»: кошка Ню (по фото нашей кошки) всё делает быстро и ставит часы неправильно — перепутаны стрелки, час больше или меньше, «цифра — это минуты», «ровно» вместо «половины». Ребёнок переставляет стрелки на нужное время, а Ню объясняет, что перепутала (`src/js/nyu-errors.js`).

Каждая глава открывается вступлением-комиксом: реплики героев появляются по одной, как в переписке (нажатие на диалог — следующая реплика, внизу «Пропустить»). Реплики читаются вслух, у каждого героя свой голос. Тексты — в `src/js/i18n/story-texts.js`, раздел `comics`.

Герой говорит фразы по времени дня («Пора завтракать?» — только с 7 до 10 утра, «Пора спать?» — с 20:30 до 22:00) и читает их вслух, если включён звук. Время на часах выбирается только из интервала фразы, а в одной сессии (прохождении остановки) фразы и реплики героев не повторяются; набор фраз и интервалов — в `src/js/phrases.js`, проверка — `npm run check:phrases`.

В каждой главе 4 остановки по 5 вопросов, следующая открывается после предыдущей. Часы простые (без зверушек), есть подсказки, и сначала спрашиваются часы, потом минуты. Прогресс хранится в браузере.

## Классика
Переход по кнопке «Классический режим» внизу экрана глав.
- 🎓 **Обучение** — подсказки, объяснения, можно пробовать снова; сначала часы, потом минуты (и выбором, и стрелочками).
- 🏆 **Игра** — без подсказок, одна попытка (выбор из 4 или ввод времени).
- 🕒 **Найди часы** — по времени выбрать правильные стрелочные часы.

5 уровней: от «ровно час» до «любые минуты».

## Разработка
Нужен Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev       # сервер разработки с горячей перезагрузкой
npm run build     # production-сборка в dist/
npm run preview   # посмотреть собранную версию
```

Открой страницу с `?debug` (например, `http://localhost:5173/?debug`), и состояние игры будет доступно в `window.__state` — это нужно автотестам.

## Структура
```
index.html            разметка (тексты подставляются из src/js/i18n)
src/main.js           точка входа
src/styles/           CSS: base, menu, game, story, animations, responsive
src/js/
  state.js            общее состояние игры
  levels.js           уровни и режимы
  i18n/               тексты (ru.js, en.js, story-texts.js) и переключение языка
  game.js             ход игры: вопросы, ответы, обратная связь, итог
  menu.js             меню классики: язык, режим, список уровней
  story.js            «История с Барсиком»: главы, остановки, прогресс, реплики
  nyu-errors.js       ошибки Ню для игры «Найди ошибку»
  album.js            альбом наклеек и гардероб Барсика
  outfits.js          наряды Барсика: рисунки, пороги звёзд, выбранный наряд
  clock-themes.js     оформление часов для каждой остановки истории
  comic.js            вступление к главе: комикс-переписка с озвучкой
  phrases.js          фразы истории и их интервалы времени дня
  art.js              SVG-рисунки: Барсик, друзья, иконки наград
  animals.js          зверушки на циферблате классики
  clock.js            рисование часов в SVG
  explain.js          объяснения «что пошло не так»
  speech.js           чтение вслух
  audio.js, effects.js  звуки и анимации
  fullscreen.js, ui.js  полный экран, переключение экранов
src/sw.template.js    шаблон service worker (список файлов подставляет vite.config.js)
public/               manifest.json и иконки
```

## Публикация
GitHub Actions (`.github/workflows/pages.yml`) собирает проект и публикует `dist/` на GitHub Pages при каждом пуше в `main`. В pull request выполняется только проверка сборки. В настройках репозитория должен быть включён Pages с источником **GitHub Actions**.
